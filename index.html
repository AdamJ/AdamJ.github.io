Camp 2 · How I work

Gate the connectors and data scope, not the creativity.

  • Show the work

    People trust an answer when they can see how it was produced.

  • Make correcting cheap

    A wrong answer is survivable when fixing it takes seconds and the fix sticks.

  • Ask, don't hunt

    Users should state what they need, not learn where the data lives.
