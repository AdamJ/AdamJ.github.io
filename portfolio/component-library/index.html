Case study · Design systems

Web and iOS shared no visual language, so I built the first unified design system for construction management software.

A library of design tokens, components, and Storybook documentation for Component Assembly Systems, built for web and iOS.

Step 1 · Context

Construction management software across web and iOS needed one visual language and one set of reusable parts.

I built the design system for Component Assembly Systems’ construction management platform. It spans web and iOS, with a unified visual language, reusable components, and documentation that speeds up development.

Step 2 · Design tokens

Tokens came first, so every component inherits color, type, spacing, and icons from one source.

Spacing and sizing

Step 3 · Final design

Buttons, cards, tables, and form controls, specified so they are ready for production.

All design and component documentation lives in Storybook.

View Storybook

Step 4 · Impact

The first unified design system gave engineering a foundation for faster, more consistent features.

  • Established the first unified design system across web and iOS
  • Reduced design-to-development handoff time with production-ready component specifications
  • Created a foundation for rapid feature development and a consistent user experience
  • Documented design tokens and usage guidelines for the engineering team
